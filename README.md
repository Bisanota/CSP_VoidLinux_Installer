# CSP_VoidLinux_Installer
CSP pre-installation, with timelapse working (tested with 4.0 Version)

A port from my ArchLinux CSP installation script.

**DO NOT RUN THE SCRIPT WITH SUPERUSER PRIVILEGES**, instead run it as normal user.

In fact, files are from [this github repo](https://github.com/parka6060/wine-csp-patches) and some recomendations are from [this blogspot](https://offworldgirl.blogspot.com/2020/01/running-clip-studio-paint-in-wine-on.html) about Clip Studio Paint

Thanks [parka6060](https://github.com/parka6060) for Clip Studio Paint files in Wine
